# dayeon 작업 기록 — 2026-06-05

## 요약

쇼핑몰·ERP 회원/상품/테마 기능을 확장하고, Firebase 배포 준비를 마쳤습니다.

## 주요 변경

### 회원 관리 (ERP)
- 회원 목록 테이블: `등급` 컬럼 추가 (적립금액 왼쪽)
- 테이블 레이아웃: 내용에 맞게 `w-fit`, 긴 주소·메일만 말줄임
- 서브 탭 추가: **포인트/적립금**, **추천인제도**
- API: `/api/admin/settings/points`, `/api/admin/settings/referral`, 회원 적립금 수정

### 상품 관리 (ERP)
- 상품 등록: **이미지(왼쪽) / 폼(오른쪽)** 2열 배치
- 이미지 WebP 업로드, 작은 썸네일 6장
- 상품목록·재고·카테고리·필터 카데고리 ERP 연동

### 테마 (쇼핑몰 + ERP)
- **핑크테마** (기본), **깔끔테마**, **인도네시아테마** 3종
- 인도네시아: 레드·크림 톤, 전용 로고·마이정보/가방·SNS 아이콘
- ERP 테마변경 미리보기 이미지 각 테마 실제 화면으로 교체

### API·인프라
- `shop-api`: Express JSON DB, OAuth, 카탈로그, 결제수단, CMS
- `member-settings.js`, `site-theme.js` 설정 모듈
- Firebase: `hosting:shop` + `functions:shop-api` (asia-northeast3)

## 로컬 실행

```powershell
# API (3601)
cd shop-api
npm run dev

# 쇼핑몰 (3600)
cd shop-web
npm run dev
```

또는 루트: `npm run shop:api`, `npm run shop:web`

## 배포

```powershell
.\deploy-shop.bat
```

|------|-----|
