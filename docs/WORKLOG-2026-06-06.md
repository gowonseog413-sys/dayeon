# dayeon 작업 기록 — 2026-06-06

## 요약

마이페이지·포인트·ERP 회원/주문/테마 기능을 확장하고, 포인트 원장(ledger)을 도입해 쇼핑몰과 ERP가 동일한 적립·차감 내역을 실시간 공유하도록 정리했습니다.

## 주요 변경

### 마이페이지 (쇼핑몰)

- **포인트 · 등급** (`/profile/points`): 나의현황 / 등급안내 / 추천현황 탭, 포인트 획득·사용 내역(5건/페이지, NatePagination)
- **장바구니 · 위시** (`/profile/wishlist`): 장바구니 / 위시리스트 탭
- **내 프로필** (`/profile`): 마이페이지 / 배송주소 / 결제수단 통합 탭 (`ProfileMyPagePanel`, `ProfileAddressPanel`, `ProfilePaymentPanel`)
- **주문 상세** (`/order/[id]`): No. 역순, ‹ › 네비게이션
- **작성 리뷰** (`/profile/reviews`), **1:1 문의** (`/profile/inquiries`)
- 사이드바 문구 정리: 내 정보 / 포인트 · 등급 / 주문 내역 / 장바구니 · 위시 / 작성 리뷰

### ERP — 회원

- **포인트/적립금**: 정책 / 포인트회원 탭
- **내리뷰/포인트** (`/erp/users/reviews`): 내리뷰 / **포인트내역** 탭, 리뷰 포인트 설정, 전 회원 포인트 내역 20건/페이지
- **추천인제도**: 설정 / 추천현황 / 회원별 추천코드 탭
- **1:1 문의** 관리

### ERP — 주문·상품·테마

- 주문: 목록 / 주문배송 / 반품 / 최종마감 / 주문통계
- 상품: 필터 카데고리 **삭제 API** (`DELETE /api/admin/catalog/filter-fields/:id`)
- 게시물 목록 컬럼 순서: No → 등록일 → 상태 → 카테고리 → 제목
- 테마: 히어로배너, 이벤트팝업, 인덱스상단문구, 제휴배너, 채널 URL
- 통계보드, 카운터조회
- ERP 저장 성공 모달·탭 UI (`ErpContentTabs`, `ErpSaveSuccessProvider`)

### API · 포인트 원장

- `db.pointTransactions` 배열 — 모든 포인트 변동 기록
- `recordPointTransaction()`: 주문 사용·적립·환불, 리뷰, 가입, 추천, 관리자 조정
- `GET /api/points/history` — 회원용
- `GET /api/admin/point-transactions` — ERP 포인트내역 (pageSize 20)
- 기존 주문·리뷰 데이터는 최초 조회 시 1회 백필
